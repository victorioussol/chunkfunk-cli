# Code of Conduct

ChunkFunk should be a useful place for AI builders, designers, maintainers, and database users to collaborate.

## Expected behavior

- Be direct, kind, and specific.
- Assume good intent, but clarify when something is unsafe or unclear.
- Keep feedback about the work, not the person.
- Help new contributors understand the project boundaries.
- Respect that contributors may be sharing partial context from private systems.

## Unacceptable behavior

- Harassment, insults, or personal attacks.
- Posting another person's private data, credentials, or database contents.
- Pressuring contributors to share private production details.
- Repeatedly derailing issues or pull requests.
- Discriminatory language or behavior.

## Enforcement

Victor Solares is the maintainer and final reviewer for this project. The maintainer may edit, hide, or remove comments; close issues; block users; or decline contributions that make the project unsafe or hostile.

If you see a problem, report it through a GitHub issue if it is safe to discuss publicly. For security-sensitive or private information, follow `SECURITY.md` instead.
